乗合シャトルがおすすめの場合

1人または2人での旅行で、1名あたりの料金を最も重視し、同じ便で到着する他の予約済み乗客との同乗に問題がない場合に向いています。車両が安全にアクセスできる範囲で、確認済みのホテルまで送迎しますが、複数のホテルに立ち寄ることがあり、専用送迎より時間がかかる場合があります。

このサイトでいう「カッパドキア送迎」は、カイセリ空港と確認済みホテルの間の空港送迎を意味します。カッパドキア内の町から町へのローカル移動サービスではありません。

専用 Vito がおすすめの場合

5名までのグループで、予約1件につき車両1台を専用で利用したい場合に適しています。ほかの乗客のホテルには立ち寄らないため、家族、小グループ、時間に余裕が少ない方、荷物が多い方には実用的な選択です。

専用 Sprinter がおすすめの場合

人数が多く、最大16名まで乗れる車両が必要な場合に適しています。乗合シャトルの1名料金よりも、グループ全員が同じ車両で一緒に移動することを優先したい場合に分かりやすい選択です。

ホテルまでの車両アクセスも重要です

3つのプランはいずれも確認済みの宿泊施設に合わせて手配します。カッパドキアには、狭い道や急な坂道にある洞窟ホテルやブティックホテルもあります。車両が安全に到達できる場合はホテルまで送迎します。最後の道路が車両に適さない場合は、最寄りの実用的な車両アクセス地点を乗客と確認します。

復路も同じページで手配できます

ホテルからカイセリ空港へ戻る際に、別の復路ページを探す必要はありません。出発便と想定される道路所要時間からホテル迎車時刻を計算し、確定した時刻をご案内します。

支払いとキャンセル

料金は EUR、USD、TRY のいずれかの現金でドライバーにお支払いください。カード決済は利用できません。送迎時刻の24時間前までは無料でキャンセルできます。

人数が増えると料金差はどう変わる？

乗合シャトルは1名 €15、Vito と Sprinter は車両1台あたりの固定料金です。そのため1～2名では乗合の方が通常安く、人数が増えるほど専用車との料金差が小さくなります。

荷物が多い場合は？

一般的な空港用スーツケースであれば通常は問題ありません。ただし、乗車定員と荷物容量は同じではありません。大型、追加、特殊な荷物がある場合は、予約メモに記載するか、予約前に WhatsApp でお知らせください。選んだ車両で対応可能か事前に確認できます。

ほかのホテルへの立ち寄りは影響する？

はい。乗合シャトルは他の予約済み乗客のホテルに立ち寄ることがあるため、全体の所要時間が長くなる場合があります。Vito と Sprinter は1件の予約のみで直行するため、予定がタイトなグループや追加のホテル立ち寄りを避けたい場合に便利です。
